# Sanitization map - private, not in this repository

The briefs and rubrics in this directory replace the maintainer's internal
hostnames, addresses, identities, and the external party's name with neutral
placeholders ("the RTX host", "the external party", "the secrets store"). The
mapping from placeholder to real value is kept in the maintainer's private
study workspace and is not published; it contains addresses and an email
address that would identify the estate. The briefs use the placeholders; the
staged artifacts for g05 to g08 are verbatim operator files and carry the
real identifiers, so an arm's output may quote them. Judges are instructed
to match facts, not strings: a memo that names the real host where the
rubric says "the RTX host" earns the point. Published arm outputs pass the
redaction step described in `PROTOCOL.md` before they are committed.
