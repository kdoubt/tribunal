# Decision C14 - build vs buy authentication

A 20-engineer B2B SaaS needs auth (email/password + SSO/SAML for enterprise customers, MFA). Choose:

- **A) Buy** a managed identity provider (Auth0 / Clerk / WorkOS).
- **B) Build** on a well-known open-source library (self-hosted), owning the flows.

Commit to A or B, name the single biggest risk, and give the cheapest test/criterion that would tell them they chose wrong.
