# Decision C17 - server components / SSR vs SPA

A team is building a **content-heavy B2B web app** (dashboards + lots of CRUD, SEO matters for marketing pages, interactivity matters for the app). Choose the rendering approach:

- **A) Server-side rendering / server components** (e.g. Next.js app router).
- **B) Client-side SPA** + separate JSON API.

Commit to A or B, name the single biggest risk, and give the cheapest test/criterion that would tell them they chose wrong.
