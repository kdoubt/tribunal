# Decision C15 - GraphQL vs REST for a public API

A company is launching a **public developer API** consumed by many external clients with diverse, evolving data needs (web, mobile, third-party integrations). Choose the primary API style:

- **A) GraphQL** (client-specified queries, one endpoint, schema).
- **B) REST** (resource endpoints + versioning + OpenAPI).

Commit to A or B, name the single biggest risk, and give the cheapest test/criterion that would tell them they chose wrong.
