# Decision C18 - feature flags: build vs buy

A 25-engineer org wants **feature flags + gradual rollouts + basic experimentation**. Choose:

- **A) Buy** a managed feature-flag platform (e.g. LaunchDarkly).
- **B) Build** a lightweight in-house flag service (config + SDK).

Commit to A or B, name the single biggest risk, and give the cheapest test/criterion that would tell them they chose wrong.
